# Changelog

本文件随 VSIX 发布到 Open VSX / Cursor 扩展市场，用于展示版本变更记录。

| 版本     | 日期 | 变更项 |
|--------|------|--------|
| 0.3.4  | 2026-08-19 | 1. **GitHub/GitLab 平台识别增强**：远程平台自动探测为 unknown 时，配置页新增手动选择 GitHub/GitLab 的开关，选后选项 A/B/C 按所选平台生效；Token 模式下 unknown 自动匹配 Token 格式（ghp-/glpat-）走对应 API<br>2. **异步探测兜底**：同步 hostname 匹配不到时，访问 `{origin}/api/v4/version` 判断是否为 GitLab（3 秒超时，结果缓存 5 分钟）<br>3. **浏览器创建 URL 平台感知**：`buildCreateMrUrl` 支持外部传入平台覆盖，避免 unknown 时生成错误 URL<br>4. **unknown 平台 CLI 下载**：自动探测为 unknown 时同时显示 gh 和 glab 两个下载按钮，用户可自行选择<br>5. **Token 有效期提示优化**：校验失败时优先显示具体错误原因，不再模糊显示"有效期未知"<br>6. **一键申请 MR 按钮交互优化**：不可用时直接灰显（禁用），鼠标悬停 title 显示具体原因（如"请先一键解决并推送"），不再仅点触后更新文字提示<br>7. **清除暂存按钮大小统一**：移除 `btn-sm`，与左侧按钮保持相同尺寸<br>8. **文档更新**：补充模块功能清单、各模块实现逻辑、git/gh/glab 真实指令表、Cursor 市场发布与 MCP npm 推送手动操作流程 |
| 0.3.3  | 2026-08-17 | 1. **面板打开提速**：`gh/glab auth status` 探测加 5 秒超时兑底，受限网络/代理拦截下不再把初始化挂死；探测合并为单次 spawn（次数减半）；cliStatus 结果 30 秒缓存，刷新/重开面板不重跑<br>2. **分支列表先到**：workspace 消息不再等 CLI 探测，仓库与分支秒出，Git 配置状态稍后补到<br>3. **Token 有效期提示细化**：GitHub 拿不到过期信息时区分「fine-grained 不返回有效期 / 永不过期 token 不携带 / 代理可能剥掉响应头」；GitLab 提示需 read_api 权限才能读取有效期，不再统一显示「有效期未知」 |
| 0.3.2  | 2026-08-17 | 1. **修复暗色模式亮色块**：矩阵多选分支面板底部与工具栏图标 hover 引用了未定义的 `--bg-subtle` / `--bg-hover` 变量，暗色下落到亮色兜底值；改用主题内真实 token（`--surface-soft` / `--surface-raised`），深浅两套主题均正常<br>2. **内部解耦**：移除 MCP `open_ui` / CLI `open-ui` 与浏览器 UI（uiServer、ws 依赖、webview 携带），MCP 不再反向依赖扩展源码；扩展面板入口（`vscode://` 深链与命令面板）不变 |
| 0.3.1  | 2026-08-15 | 1. **合并矩阵多选**：下拉面板勾选多条分支，一次确认加入<br>2. **fillSuggested 覆盖式**：去掉 6 条上限，二次点击不累加<br>3. **into/from 选择隔离**：切模式不再串台<br>4. **MR 候选人缓存**：同仓库同渠道 5 分钟内复用；支持 `skipCandidates` 跳过<br>5. **工具栏瘦身**：移除打开/浏览按钮，Fetch 文字按钮保留，刷新分支图/跑矩阵下放到视图区<br>6. **稳定性修复**：stopUiServer 真实关闭、push 失败清临时分支、clone 失败清残留、merge-tree stderr 兜底、platform 精准匹配、chain 循环 guard |
| 0.3.0  | 2026-08-13 | 1. **合并矩阵**：一次预演多条分支 × 多个目标的所有组合，一屏看清谁合得进去、撞在哪些文件<br>2. **矩阵当待办清单用**：从逐条解决冲突到逐条申请 MR 一路点到底，每格状态（冲突 / 已处理 / 已提 MR）实时可见；处理过没有以 git 里的实际分支为准，重开面板也不会丢<br>3. **合入顺序建议**：多条分支合进同一目标时推演最省事的次序，并指出从哪一条起需要人工。全程在 git 对象库内模拟，不切分支、不改工作区<br>4. **冲突预警常驻**（默认关闭）：后台定期检查你的分支还能不能干净合入，只在变糟时提醒<br>5. **机械冲突自动解决**：`.gitignore` 这类纯行集合文件两边各加了几行时自动取并集，不再占用人工选边<br>6. **MCP server**：新增 `@git-insight/mcp`，把分支图 / 预演 / 矩阵 / 顺序开放给任意 MCP 宿主，默认只读<br>7. **CLI**：新增 `survey`（批量矩阵）与 `merge-order`（顺序推演）<br>8. **修复**：解决完冲突或创建 MR 之后，面板按钮全部变灰点不动 |
| 0.2.1  | 2026-08-13 | 1. **界面改版**：分支图 / 合并预演 / 冲突三栏 / 配置页与弹层统一到一套视觉语言<br>2. **深浅双主题**：跟随 Cursor 主题自动切换，切换即时生效，不必重开面板<br>3. **修复**：分支图长分支名画到节点框外；冲突三栏表头与代码列错位（改为滚动吸顶） |
