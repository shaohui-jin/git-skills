# Changelog

本文件随 VSIX 发布到 Open VSX / Cursor 扩展市场，用于展示版本变更记录。

| 版本     | 日期 | 变更项 |
|--------|------|--------|
| 0.2.1  | 2026-08-13 | 1. **界面改版**：全新配色、字阶与层次，分支图 / 合并预演 / 冲突三栏 / 配置页与两个弹层统一到一套视觉语言；「橙=我的、蓝=线上」贯穿全局，选边箭头、三栏表头与色带都按这套语义上色，选中态一眼可辨<br>2. **深浅双主题**：跟随 Cursor 主题自动切换深色 / 浅色，切主题即时生效不必重开面板；代码高亮与分支图画布同步适配<br>3. **修复**：分支图长分支名画到节点框外；冲突三栏表头与下方代码列错位，表头改为滚动时吸顶，长文件里始终能看清哪栏是线上、哪栏是我的 |
| 0.2.0  | 2026-08-12 | 1. **AI 选边回传更可靠**：Agent 改为直接写回结果文件，不再依赖终端命令，Windows 下不会再因命令语法问题白等一场；**需使用 Agent 模式**（已移除手动粘贴回传）<br>2. **分批不再前功尽弃**：冲突较多自动分批时，某一批失败只把该批标为待定并继续后续批次，其余批次的裁决全部保留；单批等待上限延长到 20 分钟<br>3. **合并预演提速**：冲突正文与溯源改为并行处理；关联 PR 查询改为按需开启（CLI 加 `--pr`），默认不再逐条查询<br>4. **安全加固**：报告渲染过滤不安全 HTML；AI 回传接口加鉴权并限本机访问；冲突临时文件改用私有目录<br>5. **修复**：中文提交信息与冲突正文乱码；非英文环境下部分 git 结果解析失败；打开面板偶发不自动预演 |
| 0.1.17 | 2026-08-08 | 1. **默认远程**：配置页列出 `git remote -v` 并保存 `defaultRemote`（紧凑条置于「MR 方式」卡片顶部；AI 选边默认折叠）；fetch / 短名剥前缀 / MR / 平台探测不再写死 `origin`<br>2. **CLI / Skill**：未传 `--remote` 时读 `~/.git-insight/user-config.json`（或环境变量）再兜底；打开仓库时 `gh`/`glab` 系统与扩展内探测改为 `Promise.all` 并行<br>3. **分支图**：节点只显示短名；本地与默认远程同短名同 sha 合并为单节点；多 remote 分色 + 右上角图例；修复点击高亮链路被父组件重绘清掉<br>4. **冲突文件列**：选中行改为两行（上行文件名+角标，下行 secondary「线上 / 我的」）<br>5. 命令面板去掉「合并预演（兼容）」；`docs/guide.md` 补充指令一览、默认远程与分支图约定 |
